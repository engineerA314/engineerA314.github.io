# Junyoung Park — Portfolio

Public English portfolio and resume, served at https://engineerA314.github.io/.

This is a buildless static website. Edit `index.html` for content, `style.css` for presentation, and `assets/` for images and videos. GitHub Pages serves the root of the `codex/portfolio` branch.

The layout is a plain, single-column document: a compact profile, a project highlights list, project descriptions, experience, research, education, and awards. It uses system fonts and native links and video controls, with no JavaScript dependencies.

Preview locally with `python3 -m http.server 8772 --bind 127.0.0.1` from this directory.

Benchmark images link to their original Nari Labs reports. The distributed training diagram is reused from my earlier portfolio. Avatar videos are generated examples from the teacher training stage.
